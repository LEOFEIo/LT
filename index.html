关于拾光。

静态演示版在浏览器本地运行，不上传搜索内容；完整产品可接入你的招聘与人才数据库。

这个页面可以直接放到 GitHub Pages 吗？

可以。它是一个不依赖构建工具的单文件页面，上传到仓库根目录后即可通过 GitHub Pages 发布。搜索、筛选、收藏、弹窗和触达生成都在浏览器中运行。

人才搜索结果来自真实候选人吗？

当前公开页面使用虚构演示数据，用于展示产品交互与信息结构。正式部署时可以把候选人数据源替换为企业自己的 API 或数据库。

如何保证人才判断可信？

每条重要判断都应关联到原始工作证据，并区分可验证事实、模型推断和仍需人工确认的内容。最终招聘决策始终由人完成。

能否继续使用项目里的 Next.js 后台？

可以。根目录 index.html 是独立的 GitHub Pages 展示入口，原有 Next.js、申请流程、人才工作台与管理后台仍可部署到 Vercel。
